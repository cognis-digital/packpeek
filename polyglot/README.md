# Polyglot implementations

Parallel implementations of **packpeek** (Static packer/loader fingerprinter (C) — UPX/ASPack/Themida/MPRESS/VMProtect + entropy; emits YARA + SARIF. JSON out, CI-tested.) across 9 languages, for reference and cross-language benchmarking.

- `python/` — python implementation
- `go/` — go implementation
- `rust/` — rust implementation
- `typescript/` — typescript implementation
- `c/` — c implementation
- `cpp/` — cpp implementation
- `java/` — java implementation
- `ruby/` — ruby implementation
- `csharp/` — csharp implementation
